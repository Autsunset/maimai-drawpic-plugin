# 平台配置说明

适合准备账号、模型或本地工作流的管理员。本页按“准备条件 → 必填字段 → 最小配置 → 模型限制 → 高级配置 → 常见错误”列出各平台；日常创作见[使用指南](usage.md)。

## 通用规则

在 **绘图平台 → 添加平台** 选择类型。所有类型可添加多个实例；名称去除首尾空白后按不区分大小写检查重名，必须全局唯一。多个账号、服务地址或工作流各用一个实例。

模型在创作页以 **实例名 / 模型名** 显示。模型列表逐项添加；支持别名的平台可填写 `显示名=上游模型名`，如 `图片主力=gpt-image-2.5`。短名有多个匹配时会拒绝，优先选择下拉框中的完整名称。

密钥首次配置时填写；保存后不回显明文，编辑留空保留，只有勾选清除才删除。示例中的模型都必须替换为**当前账号确实可用**的 ID，预填名称不代表开通权限；服务地址填写最终端点，API 不自动跟随重定向。

下面的最小示例是**工作台字段填写示意**，不是要粘贴进 `config.toml` 的配置块。点击 **保存平台** 后应看到平台卡片，并能在“开始创作”选择启用模型。除 ComfyUI 外，均需要平台授予的有效 API Key；勿将密钥放入反馈或截图。

## OpenAI 与兼容服务

### 准备条件

OpenAI 或兼容图片服务的账号、密钥和最终 API 地址。

### 必填字段

平台名称、API Key、服务地址、模型列表；通常地址以 `/v1` 结尾。

### 最小配置示例

```text
平台名称：图片主力
服务地址：https://api.openai.com/v1
模型：gpt-image-2.5
兼容模式：auto
```

### 模型与图生图限制

Images API 的生成、编辑能力取决于模型。RinkoAI NAI 目前只支持文生图，不能通过兼容模式绕过图生图校验。模型必须由当前账号开通。

### 高级配置

`images_api` 使用图片生成/编辑端点；New API 标准聊天绘图选 `chat_completions`，源图通过 `messages[].content[].image_url` 传入。`rinkoai` 面向 RinkoAI NAI；旧 `novelai_images_api` 读取为其别名。`auto` 优先模型端点元信息，再按模型族选择。可调整尺寸、输出格式、背景、质量、模型尺寸覆盖及额外参数；以实际模型为准。

### 常见错误

404/不支持端点：先确认地址与模式；只有明确不支持端点的错误才尝试切换格式。鉴权、配额、审核、成功响应解析/下载失败不触发换格式重绘。图生图不能静默丢掉源图。

## Google Gemini

### 准备条件

可以调用图片模型的 Google API 账号；必要时配置该平台支持的兼容地址。

### 必填字段

平台名称、API Key、已开通的图片模型；服务地址按部署填写或保留默认。

### 最小配置示例

```text
平台名称：Gemini 图片
模型：gemini-2.5-flash-image
启用：是
```

### 模型与图生图限制

参考图数量、输出尺寸和反向提示词支持因模型而异。普通文本模型不一定能生成图片；以工作台能力校验及账号权限为准。

### 高级配置

可配置输出尺寸、图片比例、提示词改写与额外生成参数。图生图使用真实图片与文本共同请求，不传未支持的 `number_of_images` 参数。

### 常见错误

模型不可用：核对账号和模型 ID。额外参数报错：删除当前 SDK/模型未声明的字段，不靠重绘掩盖参数错误。

## 智谱

### 准备条件

开通图片接口的智谱账号。

### 必填字段

平台名称、API Key、模型列表。

### 最小配置示例

```text
平台名称：智谱图片
模型：glm-image
启用：是
```

### 模型与图生图限制

当前接入仅文生图。没有 Z-Image；插件中的 `z-image-turbo` 属于阿里百炼。

### 高级配置

可设质量、尺寸、水印、用户标识与额外参数。请求核心字段为 `model`、`prompt`，不添加旧 `user` 或接口未声明的 `response_format`。没有独立反向字段时会把内容合并到提示词。

### 常见错误

图生图被拒绝是当前能力限制；不要用额外参数绕过。接口报未知参数时核对质量、尺寸和额外参数。

## 阿里百炼

### 准备条件

自己的百炼工作空间 API Key、端点及模型权限。

### 必填字段

平台名称、API Key、服务地址、模型列表；地址必须以 `/api/v1` 结尾。

### 最小配置示例

```text
平台名称：百炼图片
服务地址：https://dashscope.aliyuncs.com/api/v1
模型：qwen-image-2.0
```

### 模型与图生图限制

接入 Qwen Image、Z-Image、可灵图像和 Vidu 图像；不接入万象、创意工具、图像翻译与视频。Qwen 默认 Base64 输入；可灵/Vidu 编辑需要公网原图 URL，不能直接使用网页上传或联动 Base64。聊天适配器提供的原图 HTTP(S) URL 可以保留。Z-Image 的任务类型按模型注册表校验。

### 高级配置

可配置模型尺寸覆盖、Qwen 提示词扩写与思考、Z-Image/可灵/Vidu 参数及异步轮询间隔。可灵多图与比例、分辨率须符合模型。取得异步任务 ID 后，断线仅恢复原 ID 查询，不重新生成。

### 常见错误

地址错误：不要去掉工作空间要求的 `/api/v1`。缺原图 URL：改用具备该输入的聊天适配器或其他编辑模型。异步结果待确认：查询提供商原任务。

## 火山引擎方舟

### 准备条件

开通 Seedream 图片能力的账号与对应服务地址。

### 必填字段

平台名称、API Key、模型列表；地址按平台实际端点填写。

### 最小配置示例

```text
平台名称：方舟图片
服务地址：https://ark.cn-beijing.volces.com/api/v3
模型：doubao-seedream-4-5-251128
```

### 模型与图生图限制

任务能力按 Seedream 模型族、模型后缀与人工能力名单判断；不支持的编辑任务会提前拒绝。组图数量与参考图数量需共同满足上游限制。

### 高级配置

可设模型尺寸覆盖、端点覆盖、优化提示词、连续组图、联网搜索及部分模型的背景/输出选项。参数按模型族过滤，不能假定每个模型都支持全部字段。

### 常见错误

模型/端点不可用：核对当前账号的上游 ID。参考图过多或输出数量超限：减少数量或换支持的模型，不静默截断。

## 硅基流动

### 准备条件

平台开放的图片模型权限及密钥。

### 必填字段

平台名称、API Key、模型列表。

### 最小配置示例

```text
平台名称：硅基图片
模型：Kwai-Kolors/Kolors
启用：是
```

### 模型与图生图限制

生成与编辑模型可能不同，例如 Kolors、Qwen Image、Qwen Image Edit；输入数量按模型校验。一次按一张图片流程调用，不使用已移除的 `batch_size`。

### 高级配置

可设模型尺寸覆盖、推理步数、提示词引导和额外参数。不同模型采用 `cfg` 或 `guidance_scale` 等不同参数，不能混用。

### 常见错误

模型不能编辑：请选择编辑模型。额外字段被拒绝：核对该模型的官方字段，避免使用已退役的输出参数。

## NovelAI / NovelAPI

### 准备条件

NovelAI 或 NovelAPI 兼容服务账号与可用端点。

### 必填字段

平台名称、API Key、服务地址、启用的模型。

### 最小配置示例

```text
平台名称：NAI 插画
模型：nai-diffusion-4-5-full
默认模式：anime
```

### 模型与图生图限制

支持 V3、V4、V4.5、V5 与兼容网关；图生图仅一张源图。Background 要求 V4.5 或 V5，V3 的 Furry 需启用 `nai-diffusion-furry-3`。

### 高级配置

可设默认模式、画师、正反向词、模型尺寸、采样器、步数、引导强度、种子、图生图强度。会话模式/画师与平台默认共同作用；全平台风格只套用模板，不切数据集。`{prompt}` 与 `{{tag}}` 含义不同，详见[风格占位符](usage.md#两个占位符是什么)。

### 常见错误

尺寸无效：使用模型支持的正整数尺寸。鉴权失败不会通过更换尺寸重试。多张源图会提前拒绝。

## ComfyUI 本地工作流

### 准备条件

MaiBot 所在机器可访问的 ComfyUI；导出 **API 格式 JSON** 工作流，普通画布 JSON 不能运行。

### 必填字段

平台名称、ComfyUI 地址、工作流路径、实际提示词节点 ID；图生图另填源图节点。

### 最小配置示例

```text
平台名称：本地插画
服务地址：http://127.0.0.1:8188
文生图工作流：data/workflows/t2i.json
提示词模式：single_prompt
提示词节点 ID：替换为实际工作流节点
```

### 模型与图生图限制

工作流决定文生图/图生图能力。当前仅向一个源图节点写入一张图片；不使用图生图时可不配置其工作流。`127.0.0.1` 指 MaiBot 所在机器。

### 高级配置

标准目录为 `data/plugins/maimai-drawpic-plugin/workflows/`，默认 `t2i.json`、`i2i.json`。`data/` 前缀映射到标准数据目录，旧插件 data 绝对路径也映射；其他相对路径以插件源码目录为基准，允许显式绝对路径，如 `D:/ComfyUI/workflow.json`。`positive_negative` 分别写正反向节点，`single_prompt` 写单一节点；标准文本输入名 `text`、LoadImage 输入名 `image`，种子节点要明确填写。

### 常见错误

找不到节点/字段：检查 API JSON 的节点 ID 和 inputs，不要填画布标题。连不上本地服务：检查所在机器、端口与网络。排队成功后查询断线只查询原 prompt_id，不重复排队。
