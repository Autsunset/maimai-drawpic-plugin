# 平台配置说明

在扩展工作台“绘图平台”中按需添加。所有类型均支持多个实例，名称去除首尾空白后不区分大小写检查重名；请选择不同名称。平台卡片只显示已添加实例，所有参数均在编辑表单中设置。模型列表逐项添加；参数覆盖使用名称和值两列。密钥不回传明文，留空保留已有值。

## OpenAI 与兼容服务

服务地址通常以 `/v1` 结尾。兼容模式可选 `auto`、`images_api`、`chat_completions`、`rinkoai`。

- `images_api` 使用图片生成与编辑端点；尺寸、输出格式、背景、质量等以实际模型为准。
- New API 的聊天绘图使用 `chat_completions`；图生图通过 `messages[].content[].image_url` 传递真实源图。
- RinkoAI 的 NAI 系列使用 `rinkoai`。旧 `novelai_images_api` 值自动读取为此模式。RinkoAI NAI 当前不支持图生图。
- `auto` 优先参考服务模型端点信息。仅明确的端点不支持错误才允许切换格式，鉴权、配额、审核及响应解析失败不会触发重绘。

所有平台的多个账号、地址或工作流分别点击“添加平台”，各自命名并填写参数。模型列表以“实例名 / 模型名”区分。多个 OpenAI 兼容服务各自填写地址、密钥和模型。模型名称可用 `显示名=上游模型名`，如 `服务A图片=gpt-image-2.5`，在默认模型和绘图选择中使用显示名，避免同名模型冲突。

## Google Gemini

填写 API Key 与当前账号可用的图片模型。不同模型对参考图数量、输出尺寸和反向提示词的支持不同，以工作台能力校验及上游模型要求为准。

## 智谱

默认模型 `glm-image`，仅文生图。支持质量、尺寸、水印与用户标识；额外参数通过参数列表添加。没有独立反向字段的模型会把反向提示词合并到提示词中。

## 阿里百炼

地址使用自己的百炼工作空间端点，并以 `/api/v1` 结尾。支持 Qwen Image、Z-Image、可灵图像及 Vidu 图像，不接入视频、万象、创意工具与图像翻译。

Qwen 默认以 Base64 传入源图；可灵/Vidu 图生图要求原图公网 URL。网页上传与插件 Base64 接口不能满足这种 URL 输入要求，会在创建任务前拒绝。聊天适配器提供的原始 HTTP(S) 图片 URL 可以保留给这些模型使用。Z-Image 通常用于文生图，任务类型以模型注册表为准。

## 火山引擎方舟

统一填写一个模型列表，可配置模型尺寸覆盖、优化提示词、连续组图和联网搜索等选项。插件按 Seedream 模型族筛选官方支持的参数；任务后缀和人工能力名单一起决定文生图与图生图可用性。

## 硅基流动

填写平台开放的具体模型，如 Kolors、Qwen Image 或 Qwen Image Edit。文生图与编辑模型可能分开，源图数量按模型限制校验。

## NovelAI / NovelAPI

支持 V3、V4、V4.5、V5 与兼容网关。平台中配置默认模式、画师、正反向提示词、尺寸、采样器、步数、引导强度、种子与图生图强度。

图生图只接受一张源图。Background 模式要求 V4.5 或 V5；V3 的 Furry 模式需启用 `nai-diffusion-furry-3`。会话模式、画师与平台默认设置共同作用；全平台“风格预设”只负责提示词模板。

## ComfyUI 本地工作流

导出 ComfyUI 的 **API 格式**工作流，放到 MaiBot 的 `data/plugins/maimai-drawpic-plugin/workflows/`：文生图默认 `t2i.json`，图生图默认 `i2i.json`。普通画布 JSON 不能直接运行。

在平台编辑表单中填写 ComfyUI 地址、工作流路径、提示词及源图节点 ID。正反向分开选 `positive_negative`，只有一个提示词节点选 `single_prompt`。标准提示词输入名是 `text`，LoadImage 输入名是 `image`。多个种子节点时显式填写种子节点 ID。

配置中的 `data/` 前缀映射到标准数据目录，如 `data/workflows/t2i.json`；指向旧插件 `data/` 的绝对路径也自动映射。其他相对路径以插件目录为基准，也可以填写绝对路径。Windows 路径建议使用 `D:/ComfyUI/workflow.json`。

ComfyUI 必须能被 MaiBot 所在机器访问，`127.0.0.1` 指 MaiBot 所在机器。未使用图生图时可留空图生图工作流。当前仅向一个源图节点写入一张图片。
