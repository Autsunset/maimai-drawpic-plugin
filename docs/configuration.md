# 配置、缓存与升级

适合管理此实例的可信管理员：明确配置归属、审核与额度、缓存容量、备份和迁移冲突恢复。日常出图见[使用指南](usage.md)，其他插件开发见[联动指南](integration.md)。

目录：[配置归属](#配置归属) · [权限与审核](#权限额度与审核) · [缓存](#缓存与保留期) · [升级恢复](#升级迁移与冲突恢复) · [请求与安全](#请求与安全边界)

## 配置归属

- **绘图平台**：按需添加实例，在平台窗口点击“保存平台”，保存到标准数据目录 `platforms.json`。
- **偏好与预设**：通用与审核、风格预设共用草稿，右上角“保存全部设置”统一保存到 `workspace_settings.json`。切换分类保留草稿；离开页面仍有未保存确认。
- **MaiBot 插件配置页**：`config.toml` 只保留 `plugin`、`proxy`，管理启用开关、网络代理与缓存上限；扩展工作台不重复展示这些项目。

配置位置以 Runner 授予路径为准，常见持久目录是 `data/plugins/maimai-drawpic-plugin/`，临时目录是 `temp/plugins/maimai-drawpic-plugin/`。数据不依赖插件源码目录名。

密钥不回显，编辑时留空保留，清除须显式勾选；平台恢复默认不清除已有密钥。保存采用修订号，多页面或其他管理操作已修改配置时，过期保存会被拒绝。不要为了消除提示直接覆盖旧 JSON。

## 权限、额度与审核


管理员 ID、群聊与私聊默认额度、周期、审核开关和审核提示词在“偏好与预设 → 通用与审核”中设置。聊天中的额度管理使用 `/绘图 次数` 及其帮助提示。

- 启用次数管理后，群聊共享本群额度，私聊按用户计算；管理员不受次数限制。额度周期可按日、周、月或一次性配置。
- 发往聊天的任务在执行前预留一次额度。能力或源图校验拒绝时不扣额度；生成、审核或发送失败且没有任何图片确认送达时，正常结算会退回该次预留。至少一张已确认送达时保留本次消费。
- 预留绑定消费时的实际周期，取消与失败重复结算不会重复退款；跨周期结束的旧任务不抵消新周期的消费。提前取消也会等待预留写入结束后结算。
- 不指定 `stream_id` 的网页/联动管理调用仅生成结果，不使用聊天额度规则。调用方仍需自行验证用户权限。
- 额度文件或磁盘故障需先处理并核对日志；重启不会根据未确认的远端结果自动退款。插件额度与提供商计费相互独立，本地取消、退次数或发送未确认都不表示提供商未收费。

网页与联动入口都属于当前实例的管理能力。仅向可信管理员开放 MaiBot WebUI，仅安装可信插件。联动 API 不提供网络监听、独立令牌、平台密钥读取或任意文件读取功能。调用方插件自行负责其聊天用户的权限检查，不能直接将不可信用户参数作为管理操作。


## 缓存与保留期

在 **MaiBot 插件配置 → 插件基础配置** 中，图片缓存、日志和上传缓存可分别设置容量上限，单位 MB（按 1024² 字节计算）。默认图片 **300 MB**、日志 **10 MB**，保存配置后立即按新上限清理较旧内容，工作台不重复展示这些设置。

| 数据 | 清理策略 |
| --- | --- |
| 上传与输入源图 | 默认合计 256 MB，可独立调整；同时限制 24 小时、100 个文件；领取后移除上传中间文件 |
| 生成原图、WebP 预览与缩略图 | 共用图片缓存上限，默认 300 MB；同时限制 30 天、500 个任务，按最旧任务清理，正在使用的结果受保护 |
| 插件日志 | 当前日志与 3 份轮转备份共用日志上限，默认合计 10 MB |
| 聊天图片内存缓存 | 30 分钟 TTL、条目数量和 256 MiB 编码大小上限，卸载时释放 |
| 任务与网页元数据 | 最多 500 条任务记录，清理已淘汰任务的网页元数据 |

生成图片缓存位于 Runner 授予的 `temp/plugins/maimai-drawpic-plugin/results/`，旧数据目录中的图片缓存仍可读取，并计入同一上限。在启动、写入相关缓存时检查限制，并每 10 分钟清理过期产物。图片被清理后任务状态仍可查询，但原图与预览不再可读。单次结果超过缓存容量时会说明未缓存原因，不重新请求生图，聊天图片仍正常发送。用户工作流、密钥配置、额度记录及迁移备份不会被当作缓存删除。


## 升级迁移与冲突恢复

升级前停用或卸载旧运行实例，备份 `config.toml`、完整标准数据目录和需要保留的图片；不要先删除原目录。不要创建两个相同插件 ID 的安装。

首次加载会识别已有平台及通用配置。先保存新数据、按原始字节备份 TOML，再移除迁出的配置节；重启沿用已迁移的内容。没有旧平台时从空列表开始。编辑密钥留空保留原值，也可显式勾选清除。配置采用修订号，多个页面同时编辑时提示刷新。


如果新 JSON 配置与恢复的旧 TOML 内容不同，插件会报告冲突并保留原文件。先备份 `config.toml` 和数据目录：保留工作台配置时移走 TOML 中的旧绘图配置节；恢复旧 TOML 时先移走相应的 `platforms.json` 或 `workspace_settings.json`，再重新加载插件迁移。不要在没有备份时覆盖配置文件。

工作台设置文件升级为带自身修订号的格式；旧格式会先按字节备份再升级，平台密钥仍由 `platforms.json` 保存。平台重命名需同时更新模型引用时，使用 `workspace_config_transaction.json` 保存已提交的完整事务，再同步两个文件。该文件可能含密钥，应和配置采用相同的保管方式，不能公开或当缓存删除。

若界面提示“配置已保存，文件同步尚未完成”或“运行时刷新未完成”，说明提交已成功，不应当作普通保存失败反复提交。先检查磁盘和日志，再重新加载插件完成恢复；事务与目标文件冲突时会保留原件并拒绝覆盖。存在待恢复事务时，应一起备份事务文件与两个配置文件，先解决恢复问题，再按上面的旧配置迁移步骤操作，不要单独删除事务或改写其中一个文件。


旧插件目录中的 `data/` 及历史状态文件会校验后迁移，内容冲突时报错并保留原件。迁移备份包含原有密钥，应与数据目录一起妥善保管。


任务与幂等映射现在保存在同一个任务文件中，先原子写入再启动绘图。旧 `workspace_tasks.json` 保留读取兼容；新任务不依赖它作为唯一幂等索引。重启时未完成的任务记为待确认，不自动重放，先核对提供商记录。任务文件损坏时停止加载并保留原件，请从备份恢复，不能清空文件来假装消除问题。

迁移备份不会作为缓存自动清理；它们包含旧密钥，应由管理员定期核对并妥善保管。

## 请求与安全边界

默认首选模型与默认风格使用下拉选择，备选模型按需添加并可上移、下移。“最多重试次数”默认 0、最多 5，只对连接未建立、明确限流等可安全重试的失败生效；认证、参数和配额拒绝可按顺序改用备选，但不重复请求同一模型。审核拒绝、生成结果解析/下载失败，以及超时等远端受理状态不确定的情况均不自动重绘。恢复默认先回填当前表单，保存后生效，已有密钥保留。

ComfyUI 和阿里云异步任务取得远端 ID 后，查询短暂断线只会重试同一 ID，单次查询最多尝试 3 次，仍受平台尝试总超时限制。查询重试耗尽时错误消息保留远端 ID，不重新排队或切换备选模型；若总超时提前结束本地等待，可从任务日志查找已提交的远端 ID。远端任务仍可能继续执行。

图片结果下载仅允许 HTTP(S)，禁止地址内嵌凭据；DNS 解析后固定连接目标，并逐跳检查重定向。默认阻止内网、回环和链路本地地址；只有管理员所配置服务的**相同协议、主机及端口**可作为自托管结果地址使用，不增加额外配置开关。

平台 API 地址应填写最终服务地址，生成请求与模型查询不会自动跟随重定向。


原图与结果传输短暂失败只恢复原结果读取，不能因此重新生成。查询重试耗尽会携带远端 ID；总超时提前中止时，可从任务提交日志查找 ID。上游受理状态未知与“明确未发出”不同，不承诺 exactly-once。

网络代理在宿主插件配置中管理。私有 WebUI API 可编辑配置并查询日志，公开联动接口不提供平台密钥、配置写入、原始日志或任意路径读取。不开放独立 HTTP 服务或令牌。仅安装可信插件并限制 WebUI 管理员访问。
