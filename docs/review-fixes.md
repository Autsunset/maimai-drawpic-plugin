# WebUI 审查修复记录

针对用户提供的固定提交 `5083060` 审查报告，2026-10-15 在 `feat/webui` 完成以下修复。

| 问题 | 修复与验证 |
| --- | --- |
| R1 结果 URL 内网访问 | 所有提供商共用结果下载器，校验协议、凭据、DNS 和逐跳重定向，并将已验证 IP 固定为实际连接目标；管理员配置的同源地址支持自托管。生成及模型查询请求禁止自动重定向。使用本机 HTTP 服务验证拒绝内网 Markdown、跨源跳转、非法 URL，以及固定 IP 后保留正确 Host。 |
| R2 不安全重绘 | 结构化错误区分安全重试、明确拒绝、审核拒绝、结果失败及未知受理状态。审核拒绝为 rejected；下载/解析失败、超时及未知异常不自动重新生成。回归覆盖备用模型和额外重试同时启用的情况，以及真实模拟 HTTP 审核拒绝。 |
| R3 脱敏路径缺口 | 提供商日志参数支持嵌套结构；统一过滤器覆盖宿主 handler、全部实例和轮换前密钥；任务消息在持久化前脱敏。验证宿主日志、本地日志、任务 JSON、公开响应及长错误体。 |
| R4 并发上传超额 | 校验、容量检查、清理与原子接管使用同一个线程锁，上传不再复制成两份。双并发竞争与移动失败注入验证总容量和原件保留。 |
| R5 恢复配置冲突 | 初始化先比较旧 TOML 与已有 JSON，冲突时不改配置文件；内容相同时允许幂等完成迁移。SDK 归一化不再凭空补回已迁出的配置节。 |
| R6 轮询丢输入 | 保存未提交搜索草稿，筛选表单聚焦或中文输入期间不被自动刷新替换，并在响应返回后再次检查。浏览器等待超过轮询周期，确认内容、焦点和原节点均保留。 |
| R7 历史导航不同步 | hashchange 同步路由；取消离开时恢复当前地址，未保存确认不替换编辑表单。浏览器验证实际前进、后退与标题一致。 |

同时修复源图预览的 WebP MIME、平台关闭/刷新未保存确认、原图弹窗关闭后的后续读取、开发分支安装命令、文档 URL 和 ComfyUI 说明路径。联动指南改为有总预算的短等待示例，区分后台协程与 LLM 工具，超时保留任务句柄及原 request_id。

## 兼容性与验证范围

- 最低 Host 改为 MaiBot 1.3.6，SDK 仍为 2.12.0，Python 仍为 3.12；插件版本仍为 1.12.6。
- 结果下载固定 IP 后仍使用原主机名进行 HTTPS 证书校验，因此同步要求 aiohttp ≥3.9，manifest 与 requirements.txt 保持一致。[aiohttp 官方参数说明](https://docs.aiohttp.org/en/v3.12.6/client_reference.html#basic-api)。
- 本地使用实际 SDK 2.12.0，收集 28 个组件，实际 Host 页面声明解析通过。
- 225 项 Python 测试通过，Ruff、Python 编译和 JavaScript 语法检查通过。
- 使用实际 Host 页面脚本与隔离模拟平台，在 iframe sandbox 下验证桌面/移动端主要流程、R6/R7、未保存编辑和原图读取取消。
- Host 1.3.6 的完整部署兼容性依据用户提供的独立验证报告；本轮未重新启动完整 1.3.6 Host，也未调用真实收费平台或真实聊天。

## 报告中的后续建议

本次处理七项确认问题与相关界面、文档缺陷，没有新增长等待公开 API 或持久化任务队列。跨文件进程崩溃恢复、同步工作线程的强制停止与物理并发核算、上游撤单/计费仍需后续设计和故障验证。短等待示例不承诺 exactly-once 或取消远端计费。本轮验证不等同于全面深度安全审查。
