| 问题 | 修复与验证 |
| --- | --- |
| R1 结果 URL 内网访问 | 所有提供商共用结果下载器，校验协议、凭据、DNS 和逐跳重定向，并将已验证 IP 固定为实际连接目标；管理员配置的同源地址支持自托管。生成及模型查询请求禁止自动重定向。使用本机 HTTP 服务验证拒绝内网 Markdown、跨源跳转、非法 URL，以及固定 IP 后保留正确 Host。 |
| R2 不安全重绘 | 结构化错误区分安全重试、明确拒绝、审核拒绝、结果失败及未知受理状态。审核拒绝为 rejected；下载/解析失败、超时及未知异常不自动重新生成。回归覆盖备用模型和额外重试同时启用的情况，以及真实模拟 HTTP 审核拒绝。 |
| R3 脱敏路径缺口 | 提供商日志参数支持嵌套结构；统一过滤器覆盖宿主 handler、全部实例和轮换前密钥；任务消息在持久化前脱敏。验证宿主日志、本地日志、任务 JSON、公开响应及长错误体。 |
| R4 并发上传超额 | 校验、容量检查、清理与原子接管使用同一个线程锁，上传不再复制成两份。双并发竞争与移动失败注入验证总容量和原件保留。 |

| R7 历史导航不同步 | hashchange 同步路由；取消离开时恢复当前地址，未保存确认不替换编辑表单。浏览器验证实际前进、后退与标题一致。 |

同时修复源图预览的 WebP MIME、平台关闭/刷新未保存确认、原图弹窗关闭后的后续读取、开发分支安装命令、文档 URL 和 ComfyUI 说明路径。联动指南改为有总预算的短等待示例，区分后台协程与 LLM 工具，超时保留任务句柄及原 request_id。

## f605e561 复查后的修复

- **R2 查询阶段重绘残留**：外层不再将原始连接异常推断为“生成请求尚未发出”。仅实际 POST 传输边界可标为安全重试。ComfyUI、阿里云取得远端 ID 后进入已提交边界，网络故障只重试同 ID 查询（最多 3 次），仍失败则保留远端 ID，禁止重新排队和切换备选。明确审核拒绝及协程取消保留原语义。
- **UI-04 首段详情迟到响应**：首次 task 查询前登记请求代次；关闭时同步失效，切页、替换弹窗、较新请求及取消后的刷新均检查代次。原图分块在请求前后继续检查代次，停止后续块，不声称已发出的 SDK 请求被中止。
- **导航与无障碍小修**：非法 hash 恢复当前合法地址；使用 iframe 自身的绝对 URL 替换历史，避免 srcdoc 相对地址引起重载。普通弹窗及未保存确认均关联标题。浅/深主题主按钮使用独立前景色，减少动态效果时禁用任务卡 hover 位移。[界面检查依据](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)。

本轮新增 19 项 Python 回归：在真实插件任务计划中调用实际 ComfyUI/阿里云提交与轮询方法，模拟查询连接错误、超时、查询限流及断线恢复，启用 2 次生成重试和备选仍只提交一次；另验证 9 个实际 POST 入口的连接分类、未分类错误不重试、取消及审核语义。均不连接真实提供商。

本轮浏览器使用真实页面源码、Host SDK 脚本与本地模拟桥，保留 `sandbox="allow-scripts"` 和实际 CSP：刷新详情后关闭、首次请求中切页、快速打开 A/B 仅展示 B、关闭原图后停止后续块均通过；R6 搜索焦点、R7 前进/后退、平台未保存确认继续通过。另验证非法 hash 不重载 iframe、弹窗可访问名称、减少动态效果下 hover 无位移；360/390/768/1440/1920 宽度无页面横向溢出。浅色主按钮正常/hover 对比度为 5.062/5.337，深色为 7.747/9.393（取实际计算样式）。没有页面脚本错误。该模拟桥验证不等于完整 Host 部署验收，也未覆盖所有控件语义、读屏及慢网排列。

- 使用实际 Host 页面脚本与隔离模拟平台，在 iframe sandbox 下验证桌面/移动端主要流程、R6/R7、未保存编辑和原图读取取消。

## 报告中的后续建议

本次处理七项确认问题与相关界面、文档缺陷，没有新增长等待公开 API 或持久化任务队列。跨文件进程崩溃恢复、同步工作线程的强制停止与物理并发核算、上游撤单/计费仍需后续设计和故障验证。短等待示例不承诺 exactly-once 或取消远端计费。本轮验证不等同于全面深度安全审查。

已提交任务的查询重试耗尽会在错误中保留远端 ID；若外层总超时提前取消等待，当前任务消息可能只显示通用超时，远端 ID 需从提交日志查找，尚未新增远端句柄持久化及重启恢复机制。长表单布局、全部控件语义及正式高层联动客户端仍属后续设计建议。
