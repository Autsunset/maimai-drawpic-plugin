## 功能

- **绘图工作台**：文生图、上传源图进行图生图，选择模型、风格和结果去向。
- **按需添加平台**：只添加要使用的平台；所有类型都可添加多个实例，平台名称全局不能重复，模型按“实例名 / 模型名”区分。
- **完整配置**：平台参数、模型列表、参数覆盖、风格预设、审核和额度可在扩展页面编辑。插件开关与网络代理在 MaiBot 插件配置页管理。
- **任务与图片**：查看状态、筛选历史、预览生成图片、查看原图、取消执行中的任务。
- **运行日志**：按任务和级别查询插件日志，自动遮蔽密钥、Base64 和签名 URL。
- **聊天绘图**：支持命令及模型工具调用、会话模型、NAI 模式与画师、首选和备选模型。
- **实例内联动**：其他插件通过 MaiBot SDK 发起绘图、查询任务和图片、管理风格预设，无需令牌。

## 安装

运行要求：MaiBot `>=1.3.6`、MaiBot Plugin SDK `>=2.12.0`，Python `>=3.12`，使用该 MaiBot 版本配套的官方 Dashboard。

可以通过插件市场安装，或使用 CLI：

```bash
maibot plugin install WhiteCloudOL/maimai-drawpic-plugin
```

手动安装：

```bash
cd plugins
git clone --branch feat/webui https://github.com/WhiteCloudOL/maimai-drawpic-plugin.git
```

安装后重启 MaiBot，在 WebUI 的插件扩展页面打开“麦麦绘图”。升级已有安装时保留原有插件目录和数据，避免创建重复安装。

## 开始使用

1. 打开“绘图平台”，点击“添加平台”，选择准备使用的平台。
2. 填写 API Key、服务地址及账号可用的模型，按需调整参数并保存。未添加的平台不会出现在配置卡片中。
3. 默认自动选择已启用平台的可用模型；新增 OpenAI 平台预填 `gpt-image-2.5`。在“偏好与预设”设置默认模型、备选模型、审核和额度；模型名称来自已启用的平台。
4. 返回“开始创作”，输入提示词，选择模型与风格，然后开始绘图。
5. 图生图先切换模式并上传真实源图；任务提交后在后台执行，在“绘图任务”中查看进度和图片。

结果默认只在工作台显示，也可选择“同时发送到聊天”，加载并选择当前 MaiBot 实例已有的真实聊天会话。页面显示会话名称。发送到聊天时使用原有聊天额度与审核流程；仅网页查看的任务不计入聊天额度，仍进行提示词与图片审核。网页及联动接口合计最多同时执行 4 个任务。

图片先显示 WebP 压缩预览，点击“查看原图”读取原文件。页面提供原图预览，图片缓存保存在实例的插件临时目录。旧任务如果没有保存图片，只能查看已有状态。

## 图片平台

| 平台 | 文生图 | 图生图 | 说明 |
| --- | --- | --- | --- |
| OpenAI / 兼容服务 | 支持 | 视模型而定 | Images API、New API Chat Completions、RinkoAI NAI |
| Google Gemini | 支持 | 视模型而定 | Gemini 与平台提供的图片模型 |
| 智谱 | 支持 | 不支持 | 默认 `glm-image` |
| 阿里百炼 | 视模型而定 | 视模型而定 | Qwen Image、Z-Image、可灵图像、Vidu 图像 |
| 火山引擎 | 视模型而定 | 视模型而定 | Seedream 各版本与任务能力识别 |
| 硅基流动 | 视模型而定 | 视模型而定 | Kolors、Qwen Image / Edit 等 |
| NovelAI / NovelAPI | 支持 | 支持单张源图 | V3、V4、V4.5、V5，NAI 模式与画师 |
| ComfyUI | 支持 | 配置工作流后支持 | 本地或局域网 API 格式工作流 |

具体模型须在账号上开通。插件只处理图片；不同模型的任务类型和源图数量分别校验，不会静默丢弃源图或把图生图改成文生图。需要公网原图 URL 的可灵/Vidu 模型可通过支持原图 URL 的聊天适配器使用，网页上传与 Base64 联动入口会提前拒绝。[查看平台配置说明](docs/platforms.md)。

## 配置与数据

平台配置保存在 Runner 授予的 `data/plugins/maimai-drawpic-plugin/platforms.json`，绘图通用参数与预设保存在 `workspace_settings.json`。`config.toml` 仅保留 `plugin` 与 `proxy`，在 MaiBot 插件配置页管理；工作台不显示这两类设置。

首次加载会识别已有平台及通用配置。先保存新数据、按原始字节备份 TOML，再移除迁出的配置节；重启沿用已迁移的内容。没有旧平台时从空列表开始。编辑密钥留空保留原值，也可显式勾选清除。配置采用修订号，多个页面同时编辑时提示刷新。

默认首选模型与默认风格使用下拉选择，备选模型按需添加并可上移、下移。“最多重试次数”默认 0、最多 5，只对连接未建立、明确限流等可安全重试的失败生效；认证、参数和配额拒绝可按顺序改用备选，但不重复请求同一模型。审核拒绝、生成结果解析/下载失败，以及超时等远端受理状态不确定的情况均不自动重绘。恢复默认先回填当前表单，保存后生效，已有密钥保留。

ComfyUI 和阿里云异步任务取得远端 ID 后，查询短暂断线只会重试同一 ID，单次查询最多尝试 3 次，仍受平台尝试总超时限制。查询重试耗尽时错误消息保留远端 ID，不重新排队或切换备选模型；若总超时提前结束本地等待，可从任务日志查找已提交的远端 ID。远端任务仍可能继续执行。

图片结果下载仅允许 HTTP(S)，禁止地址内嵌凭据；DNS 解析后固定连接目标，并逐跳检查重定向。默认阻止内网、回环和链路本地地址；只有管理员所配置服务的**相同协议、主机及端口**可作为自托管结果地址使用，不增加额外配置开关。

平台 API 地址应填写最终服务地址，生成请求与模型查询不会自动跟随重定向。

如果新 JSON 配置与恢复的旧 TOML 内容不同，插件会报告冲突并保留原文件。先备份 `config.toml` 和数据目录：保留工作台配置时移走 TOML 中的旧绘图配置节；恢复旧 TOML 时先移走相应的 `platforms.json` 或 `workspace_settings.json`，再重新加载插件迁移。不要在没有备份时覆盖配置文件。

在 **MaiBot 插件配置 → 插件基础配置** 中，图片缓存、日志和上传缓存可分别设置容量上限，单位 MB（按 1024² 字节计算）。默认图片 **300 MB**、日志 **10 MB**，保存配置后立即按新上限清理较旧内容，工作台不重复展示这些设置。

| 数据 | 清理策略 |
| --- | --- |
| 上传与输入源图 | 默认合计 256 MB，可独立调整；同时限制 24 小时、100 个文件；领取后移除上传中间文件 |
| 生成原图、WebP 预览与缩略图 | 共用图片缓存上限，默认 300 MB；同时限制 30 天、500 个任务，按最旧任务清理，正在使用的结果受保护 |
| 插件日志 | 当前日志与 3 份轮转备份共用日志上限，默认合计 10 MB |
| 聊天图片内存缓存 | 30 分钟 TTL、条目数量和 256 MiB 编码大小上限，卸载时释放 |
| 任务与网页元数据 | 最多 500 条任务记录，清理已淘汰任务的网页元数据 |

生成图片缓存位于 Runner 授予的 `temp/plugins/maimai-drawpic-plugin/results/`，旧数据目录中的图片缓存仍可读取，并计入同一上限。在启动、写入相关缓存时检查限制，并每 10 分钟清理过期产物。图片被清理后任务状态仍可查询，但原图与预览不再可读。单次结果超过缓存容量时会说明未缓存原因，不重新请求生图，聊天图片仍正常发送。用户工作流、密钥配置、额度记录及迁移备份不会被当作缓存删除。

旧插件目录中的 `data/` 及历史状态文件会校验后迁移，内容冲突时报错并保留原件。迁移备份包含原有密钥，应与数据目录一起妥善保管。

## 聊天命令

```text
/绘图 帮助
/绘图 模型
/绘图 模型 模型名称
/绘图 文生图 夜晚的海边灯塔，水彩插画
/绘图 文生图 一座雪山 --反向 模糊，水印，文字
/绘图 图生图 保留人物和构图，把背景改成樱花树林
/绘图 状态
```

图生图命令与图片一起发送，或回复包含图片的消息。文生图命令带真实图片时会提示切换模式；图生图找不到真实图片时直接提示补图。也可以直接让麦麦画图，由模型调用绘图工具。

在“偏好与预设 → 风格预设”添加名称、说明和正反向提示词模板。`{prompt}`、`{negative_prompt}` 分别替换本次提示词；没有占位符时自动追加。风格适用于所有平台，不改变 NovelAI 数据集模式。

```text
/绘图 风格
/绘图 风格 水彩 一座被森林环绕的小木屋
/绘图 风格 默认 雨后的城市
/绘图 nai 模式 furry
/绘图 nai 画师 artist:example_name
/绘图 nai 文生图 一只在森林中散步的狐狸
/绘图 nai 参数
```

附带图片的风格绘图自动采用图生图。NAI 模式与画师使用“跟随”恢复默认值。

## 权限、额度与审核

管理员 ID、群聊与私聊默认额度、周期、审核开关和审核提示词在“偏好与预设 → 通用与审核”中设置。聊天中的额度管理使用 `/绘图 次数` 及其帮助提示。拒绝不支持的模型、任务或源图数量后不会创建任务或扣额度；生成、审核或发送失败按原有额度规则处理。

网页与联动入口都属于当前实例的管理能力。仅向可信管理员开放 MaiBot WebUI，仅安装可信插件。联动 API 不提供网络监听、独立令牌、平台密钥读取或任意文件读取功能。调用方插件自行负责其聊天用户的权限检查，不能直接将不可信用户参数作为管理操作。

## 插件联动

其他插件声明 `api.call` 能力，通过 `self.ctx.api.call("maimai-drawpic-plugin.drawpic_submit", version="1", prompt="...")` 调用。公开接口覆盖模型能力、提交、查询、取消、图片读取和预设增删改查。

所有调用由当前 MaiBot Host 转发，只能访问该实例中的任务、平台与数据；插件不开放跨实例或外网 HTTP 接口。`public=True` 表示允许该 Host 中的其他插件调用。[完整参数、错误处理和示例](docs/integration.md)。

## 常见问题

- **工作台没有模型**：添加并启用平台，确认模型列表非空；平台存在并不代表账号有模型权限。
- **图生图被拒绝**：检查模型任务类型、真实源图和参考图数量。智谱及部分图片模型仅支持文生图。
- **网页请求超时**：操作可能已完成，先查看任务列表。联动提交可使用相同参数和 `request_id` 安全重试。
- **ComfyUI 找不到工作流**：使用 API 格式 JSON，放到标准数据目录的 `workflows/` 中；核对提示词、源图、种子节点 ID。
- **查看日志**：在“运行日志”筛选任务 ID；报告问题时附插件、SDK、MaiBot 版本及脱敏日志，不要提供密钥或完整图片 Base64。

问题反馈：[GitHub Issues](https://github.com/WhiteCloudOL/maimai-drawpic-plugin/issues)。
